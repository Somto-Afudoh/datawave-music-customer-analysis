# DataWave Music Customer Analytics

## Project Overview

This project explores customer engagement, subscription behaviour, and churn patterns for **DataWave Music**, a fictional global music-streaming company.

The project is based on the **Institute of Analytics (IoA) Student Sprint: Analytics Task Challenge**.

Using Python, the aim is to clean, explore, and analyse customer data to identify meaningful patterns and provide data-driven recommendations that could help improve customer engagement, retention, and business decision-making.

## Business Objectives

The analysis will focus on answering the following questions:

1. How does customer engagement vary across subscription types?
2. What relationships exist between listening behaviour, customer satisfaction, and churn?
3. Which customer segments appear to have higher churn rates?
4. How do engagement and satisfaction differ across countries and regions?
5. What actionable recommendations could help DataWave improve customer retention?

## Dataset

The dataset contains approximately 700 customer records, including information about:

- Customer demographics and geographical location
- Subscription plans
- Listening behaviour and music preferences
- Customer satisfaction ratings
- Customer churn
- Account registration and activity dates

The dataset contains intentional data-quality issues, providing opportunities to practise data cleaning, validation, and exploratory analysis.

**Data source:** Institute of Analytics Student Sprint (Autumn 2025).

*Note: The original dataset is not currently included in this public repository.*
